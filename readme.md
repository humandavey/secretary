# secretary

A menu-bar tutor that draws while it talks.

Ask anything. When the question needs your screen, Secretary looks at it. It can draw on the screen and open a whiteboard for equations, graphs, and diagrams, timed with the spoken explanation.

## How to use it

1. Open the menu-bar icon and paste an API key under Model (OpenAI or a local vision model).
2. Tap the orb and speak, or type a question.
3. Use **Demo** to play a built-in lesson with no model.
4. Talk back to continue the same thread. **New thread** clears the conversation and drawings, but keeps personal memory.

## Features

- Timed lessons: spoken lines with animated screen and board ink
- Whiteboard for strokes, text, LaTeX, and plots (rendered by the app, not as HTML)
- Conversation threads with interrupt-and-continue
- Local personal memory for learning style, interests, and lasting facts
- Screen Recording when a question needs the screen
- Bring your own API key
